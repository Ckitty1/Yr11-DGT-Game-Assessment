# Yr11-DGT-Game-Assessment
All official work for my year 11 digital tech game assessment

EXTRA COMMIT NOTES:

Version 1.0+ - Needs pygame installed (...pip install pygame)

Version 1.16 - Optimizations: Also made it so that the world only draws onto the screen every time something actually changes instead of constantly drawing it 60fps

Version 1.17+ - To run the cut scenes, you will also need pyvidplayer2 installed (...pip install pyvidplayer2) and the "ffmpeg-9.0.1-essentials_build" file folder downloaded in the right file pathway (gyan.dev/ffmpeg/builds under "release builds")
